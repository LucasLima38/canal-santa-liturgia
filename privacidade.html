Política de Privacidade

Última atualização: 22 de novembro de 2026

Esta política vale para o canal Santa Liturgia e para o aplicativo interno "Publicador Estúdio" (no TikTok, "Santa Liturgia Publicador"), que envia os vídeos do canal ao YouTube, ao Instagram e ao TikTok.

Quem usa o aplicativo

O Publicador Estúdio é usado somente pelo responsável pelo canal Santa Liturgia, no próprio computador. Ele não é distribuído nem oferecido a outras pessoas.

Quais dados o aplicativo acessa

Com a autorização do dono do canal, pelo login do Google (OAuth), o aplicativo usa a YouTube Data API para:

  • enviar vídeos ao canal Santa Liturgia;
  • definir título, descrição, tags, miniatura, playlist e data de publicação desses vídeos;
  • ler o nome do canal, para confirmar que o envio vai para o canal certo.

O aplicativo não lê, coleta nem armazena dados de espectadores, comentários, inscritos ou de qualquer outra conta.

Onde os dados ficam

A credencial de acesso fica salva apenas no computador do responsável pelo canal. Nenhum dado é vendido, compartilhado com terceiros ou enviado a outros servidores além dos do Google/YouTube.

Serviços de API do YouTube

▶ O Publicador Estúdio usa os Serviços de API do YouTube (YouTube API Services). Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. Os dados tratados pelo YouTube seguem a Política de Privacidade do Google (https://policies.google.com/privacy).

Instagram

Com a autorização do dono da conta @canalsantaliturgia, o aplicativo usa a API do Instagram (Meta) somente para publicar os Reels do canal, com legenda e capa, e ler o nome da conta. Os dados tratados pela Meta seguem a Política de Privacidade do Instagram.

TikTok

Com a autorização do dono da conta do canal no TikTok, pelo Login Kit, o aplicativo usa a Content Posting API do TikTok somente para:

  • ler as informações básicas da conta (nome e foto), para confirmar que o envio vai para a conta certa;
  • enviar e publicar os vídeos do canal, com legenda e configuração de privacidade.

O aplicativo não lê, coleta nem armazena dados de seguidores, comentários ou de qualquer outra conta. Os dados tratados pelo TikTok seguem a Política de Privacidade do TikTok.

Cookies e dados no dispositivo

O aplicativo não usa cookies nem rastreadores. Ele guarda apenas o token de acesso OAuth no computador do responsável pelo canal, para não precisar entrar a cada envio.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de configurações de segurança do Google: https://myaccount.google.com/permissions. No Instagram, em Configurações → Apps e sites. No TikTok, em Configurações e privacidade → Segurança → Apps e serviços (Gerenciar permissões do app).

Exclusão de dados

Os únicos dados guardados pelo aplicativo são o token de acesso e uma lista local dos vídeos já enviados (ID do vídeo, título e data). Ao revogar o acesso, o token deixa de funcionar e é apagado do computador. Para pedir a exclusão de qualquer dado, escreva para o e-mail de contato abaixo: a exclusão é feita em até 7 dias. Dados obtidos da API do YouTube não são guardados por mais de 30 dias sem serem atualizados.
